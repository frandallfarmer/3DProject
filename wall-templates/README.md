This project was inspired by the paper terrain from Paper Realms.

See https://paperrealms.com for links to their various paper terrain models, including several different wall designs (some shown in the photos you can see in the /media directory.

## Instructions

These .png files are templates you can use to create your own custom textured walls: 

1) Open the wall size you want in an image editor and paste your wall texture between the silver posts

2)  Print on heavy cardstock (at least 65lb/175gsm),

3) Cut using 

   a hobby knife or

   the matching file provided in ./cutfiles with a Silhouette cutting machine

4) Fold in half and use a black marker to edge the top/bottom.

5) Glue.

6) Let dry under some weight.

7) Enjoy!
